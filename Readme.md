### 1. Baixar e instalar Python

Se não tem o Python instalado, faça o download aqui: [Baixar Python](https://www.python.org/downloads/)

### 2. Cria ambiente virtual

```PowerShell
  python -m venv venv
```

### 3. Ativar ambiente virtual no PowerShell

```PowerShell
  .\venv\Scripts\Activate.ps1
```

### 4. Instala Dependências

```PowerShell
  pip install -r requirements.txt
```

### 5. Executa projeto

```PowerShell
  python compare_data_tables.py
```
